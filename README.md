# Self-Care Website

An integrated web-based platform designed to support **mental, physical, and emotional well-being** through personalized self-care tools and resources. This website combines mental heatlh counselling chatbot, with habit tracking system and Book Recommendation tool.

## 📌 Project Overview

The **Self-Care Website** combines multiple self-care and personal development features into a single platform. The project focuses on providing users with personalized support, helping them build healthy habits, and recommending resources aligned with their self-improvement goals.

### 🧠 1. Virtual Counselor

A virtual counselor designed to engage with users and provide **empathetic, context-aware responses** to their inputs.

* Uses conversational data from the **CounselChat** dataset.
* The dataset contains conversations between individuals seeking assistance and corresponding counselor responses.
* The system uses the conversation context and user input to generate responses.
* Provides personalized self-care suggestions that can be incorporated into the user's routine.

### 📅 2. Habit Tracker

A habit-tracking feature that allows users to turn self-care recommendations and personal goals into actionable routines.

* Create and define personal habits and goals.
* Track daily progress over time.
* Monitor consistency and progress toward established goals.

### 📚 3. Book Recommendation System

A recommendation component that suggests **books and journals** related to users' personal development and self-improvement needs.

* Provides recommendations based on areas of interest and personal development.
* Helps users discover relevant self-help and wellness resources.

## 🛠️ Technology Stack

**Languages & Frameworks:** Python, Flask, HTML, CSS, JavaScript

**Libraries & Tools:** Pandas, NumPy, Scikit-learn, NLTK, BeautifulSoup, Matplotlib, Seaborn, Git, GitHub

## 🎯 Objective

The project brings **conversational support, habit tracking, and personalized resources** together in one platform, providing users with tools to develop healthier routines and support their overall well-being.

> **Note:** The virtual counselor is intended as a self-care/support feature and is not a substitute for professional mental-health care.
